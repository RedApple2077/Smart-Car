# 循迹功能调试日志

本文记录 LF04 四路红外模块、两轮驱动和正式循迹固件的实际调试过程。记录日期为 2026-11-12。它是本次功能实现与实车验证的证据索引，不替代赛道复测。

## 1. 安全约束

- ST-Link 3.3 V、车载电池和 Type-C 的目标板 VCC 不得同时连接。
- 本日志所述烧录与调试均在仅 ST-Link 向目标板供电、车载电源断开的状态下进行。
- 电机驱动在上电后保持 TB6612 `STBY` 低；必须短按并释放 `PB5` 才能启动循迹；长按停止。
- 需要切换为车载电源时，必须先断开 ST-Link 并确认其 3.3 V 线已拔除，之后才能接通车载电源。本次没有执行该切换。

## 2. 硬件识别与连线确认

### 2.1 LF04 接线与极性

| LF04 输出 | MCU 引脚 | 车体位置 | 结论 |
|---|---|---|---|
| `O1` | `PB12` | 最左 | 已确认 |
| `O2` | `PB13` | 左中 | 已确认 |
| `O3` | `PB14` | 右中 | 已确认 |
| `O4` | `PB15` | 最右 | 已确认 |

LF04 使用 3.3 V 供电，四路输入均从 `GPIOB->IDR` 的 bit12..bit15 单次快照读取：

```c
raw = (GPIOB->IDR >> 12) & 0x0F;
black_mask = (~raw) & 0x0F;
```

实测模块指示灯为“检测到黑线时点亮”，即低电平有效：白纸上四灯熄灭、黑线处相应灯点亮。结果如下。

| 场景 | 预期 `raw` | 预期 `black_mask` | 实测结论 |
|---|---:|---:|---|
| 白纸 | `0x0F` | `0x00` | 四灯灭，确认 |
| O1 压黑线 | `0x0E` | `0x01` | 对应左侧通道，确认 |
| O2 压黑线 | `0x0D` | `0x02` | 确认 |
| O3 压黑线 | `0x0B` | `0x04` | 确认 |
| O4 压黑线 | `0x07` | `0x08` | 对应右侧通道，确认 |
| O2、O3 同时压线 | `0x09` | `0x06` | 中心直行状态，确认 |
| 四路同时压黑 | `0x00` | `0x0F` | 十字路口候选，确认 |

探头悬空时看到全暗属于距离过大、无法接收足够反射光的正常现象；安装时应使各探头朝向赛道，使用白底/黑线完成标定，不以悬空状态作为白底判据。

### 2.2 驱动与编码器

- 两个驱动轮均已确认可同向前进。
- 实车对应关系已确认：右轮主要由 `TIM3` 编码器计数，左轮主要由 `TIM2` 编码器计数。
- 两侧编码器均能产生计数。
- 运行态的编码器保护仅在发车后 2 秒内左右两侧都没有计数变化时停机；单侧短暂漏计数不会触发停车。

## 3. 实现与策略演进

### 3.1 正式循迹入口

新增 `sc_track` 控制器，并在非 `SC_BUILD_HC05_BENCH` 的正式固件中接入：

```text
LF04 原始快照 -> sc_line_service -> sc_track_controller_step
    -> sc_tb6612_apply -> TB6612FNG -> 左右驱动轮
```

控制器只输出左右 PWM 千分比，不直接访问 GPIO。主循环每次迭代都采集 LF04 并更新线路状态，随后执行编码器服务和循迹服务。

### 3.2 线型处理

| `black_mask` | 含义 | 当前动作 |
|---:|---|---|
| `0x06` | O2、O3 居中压线 | 左右同速直行 |
| `0x0F` | 四路同时压黑，十字候选 | 左右同速直行，不拐入横向路径 |
| `0x02`、`0x04` | 轻微左/右偏移 | 差速微调，黑线回到 O2、O3 之间 |
| `0x03`、`0x0C` | 连续双通道偏移 | 更强差速转向 |
| `0x01`、`0x07`、`0x08`、`0x0E` | 大偏移或直角弯 | 内侧轮停止、外侧轮前进 |
| `0x05`、`0x09`、`0x0A`、`0x0B`、`0x0D` | 非连续组合 | 按四路位置的加权重心进行微调；对称组合直行 |
| `0x00` | 四路均未检测到黑线 | 沿最近一次有效偏移方向紧凑搜线，最长 1000 ms |

找线状态采用低前进量、高转向差速，避免过去以较大前进量绕大圈才重新压到黑线。重新检测到任意有效黑线组合后，立即退出找线状态并恢复普通循迹。

### 3.3 已修复的问题

1. 初版只识别连续黑线组合。丢线后重新捕获到 `0x05`、`0x09`、`0x0A`、`0x0B`、`0x0D` 等非连续组合时，程序会误判异常并停车。
   - 修复：用四路加权重心处理全部非零合法掩码，不再因这些组合停止。
2. 初版丢线找回持续 500 ms，无法覆盖传感器间距较大或弯道的短时全白状态。
   - 修复：找回窗口改为 1000 ms；超过窗口仍未检测到黑线才安全停车。
3. 丢线找回时车辆会以大半径转一圈。
   - 修复：搜线内侧轮改为极低输出、外侧轮保留转向输出，形成更紧凑的找线弧线。
4. 十字路口四路全亮时可能选择横向路径。
   - 修复：`black_mask=0x0F` 固定左右同速前进。

## 4. 速度调参记录

速度由 `Core/Src/sc_track.c` 中统一缩放系数控制，所有直行、微调、转弯和找线指令同时缩放，以保留各状态的左右差速比例。

| 阶段 | 中心直行指令 | 结果与后续决策 |
|---|---:|---|
| 初始实现 | `299/1000` | 可循迹，随后按实车需求加速 |
| 第一次加速 | `449/1000` | 约为初始速度的 1.5 倍；弯道动态误差增大 |
| 灵敏度修正 | `449/1000` | 加大偏移差速、急弯内侧停轮、搜线收紧 |
| 降至 0.8 | `359/1000` | 保留全部差速比例 |
| 提升至 1.2 | `431/1000` | 实车反馈精度下降 |
| 当前版本 | `396/1000` | 为上一版的 0.92，保留灵敏纠偏与紧凑搜线 |

当前输出（PWM 千分比）如下，左右互换时用于相反方向：

| 状态 | 左轮 | 右轮 |
|---|---:|---:|
| 中心直行/十字直行 | 396 | 396 |
| 轻微左偏 | 221 | 526 |
| 中度左偏 | 106 | 549 |
| 大幅左偏 | 0 | 564 |
| 向左搜线 | 30 | 473 |

这些为开环 PWM 指令，不等同于实际轮速。工程当前尚未实现轮速闭环/PID，赛道表现仍会受电池电压、地面摩擦、两侧电机差异和探头高度影响。

### 5.2 目标板烧录

- 目标：STM32F103C8T6，设备 ID `0x00006410`，Flash 64 KiB。
- 使用 ST-Link SWD 连接；观察到目标电压约 3.31 V。
- `build/Debug/Smart-Car.elf` 已多次使用 OpenOCD 烧录并通过 `verify`。
- 每次烧录后的 GPIOB ODR 检查为 `0x00000010`，`PB8/TB6612_STBY` 为低，满足待机安全条件。
- 曾出现一次烧录命令中 ELF 路径转换错误，OpenOCD 未能打开固件文件并明确报告烧录失败；该次没有写入。修正路径后重新烧录和校验均成功。

### 5.3 仍需赛道复测的项目

- 用当前 `396/1000` 参数在完整比赛赛道连续运行，特别观察急弯、间距较大的 O1/O2 与 O3/O4 区间、十字路口和短时丢线。
- 检查 LF04 高度约 3 cm、探头与赛道平行、环境光和每个电位器阈值一致。
- 在仅车载电源运行前，严格执行单电源切换流程。
- 如需进一步提高速度或一致性，应先实施左右轮速度闭环和轮径/编码器标定，不能仅依赖继续提高 PWM。

## 6. 当前使用方法

1. 保持单一供电源。烧录/调试时仅接 ST-Link；运行赛道前先断开 ST-Link 再接车载电源。
2. 将车放在白底黑线赛道，确保 O2、O3 位于黑线附近。
3. 短按并释放 PB5，正式循迹开始。
4. 任意时刻长按 PB5，或持续丢线超过 1000 ms，车辆进入安全停止并拉低 STBY。
